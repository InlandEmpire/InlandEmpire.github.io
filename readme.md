# Tristan Lungreen | Portfolio
## A personal website.
Started in mid-2023, this is a hobby website-- the first I'd made at the time.
Its purpose is to serve as a professional introduction to myself, showcase my resumé, and provide a platform for my own longer-form writing as needed.
Though I don't write much relevant to the blog, there are occasionally entries added.

### How was this made?
When I first started on this website, I only had a QA's understanding of HTML and CSS. Using the then-new ChatGPT and a number of online resources, I learned HTML and CSS well enough to slowly put together this project.
This site is *not* vibe-coded. Early LLM models helped me understand some concepts, but they were too rudimentary to efficiently generate more than the most basic scripts.
Mostly, this site was built using a lot of trial and error. Unlike my later projects, the structure of this one is the complete nonsense only an absolute beginner is capable of. Whenever I come back to this website to change or add something to it, I wonder what on earth I was thinking years ago. I may someday rebuild this site, but it does its job for the time being. Just don't judge its code too harshly!
This site is hosted through Github's "Github Pages" service.

That's an emblem I made to represent my online professional persona-- Inland Empire. Think of it like a personal logo. I have a few of those for different projects. This one is related to those.
